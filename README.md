# Memory Game

A fun and interactive memory game for two players, built with HTML, CSS, and JavaScript.

<img width="243" alt="image" src="https://github.com/user-attachments/assets/e3df0a1a-43fa-4afc-b539-10b3f486aa9d">

## Features

- Two-player game
- Dynamic scoreboard
- Customizable player names
- Fruit emoji cards
- Responsive design

## How to Play

1. Enter player names (optional)
2. Click on cards to reveal them
3. Match pairs of cards to score points
4. The player with the most matches wins the game
5. Click "New Game" to start a fresh round

## Installation

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/memory-game.git
   ```
2. Navigate to the project directory:
   ```
   cd memory-game
   ```
3. Open `index.html` in your preferred web browser.
